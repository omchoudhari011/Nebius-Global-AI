Custodian Architecture

Custodian is a single-user AI assistant that remembers things about you, uses your tools only with your permission, and runs scheduled jobs. This page shows how its parts fit together and the path a chat message takes through them.

  • Python backend
  • SQLite + FTS5
  • APScheduler
  • Fernet encryption
  • Nebius Nemotron
  • Mobile app

A chat message, step by step

  1. 1

    Your message arrives through POST /chat. The orchestrator opens a chat thread in conversations (for a new chat) and saves your text in messages.

  2. 2

    memory.recall() searches the FTS5 index memories_fts, reads the matching memories, and links them to the reply in message_memories.

  3. 3

    The orchestrator picks a skill from skills by keyword. Its prompt template shapes the model call.

  4. 4

    The model backend gets the conversation history and the prompt, and returns a reply that may propose tool calls. The reply is saved in messages with its skill_id.

  5. 5

    Each proposed tool call goes through the tool gate. Its result comes back as a tool message.

  6. 6

    The final reply is saved in messages, and new facts go to memories (encrypted) and memories_fts (the search index).

  7. 7

    The reply and the list of memories used go back to the app: the chat screen and the Active Context rail.

Two more paths

A scheduled task

app/scheduler.py, at each task's cron time

  1. Inserts a task_runs row with status running.
  2. Opens a conversations row with channel task and runs the same orchestrator steps as a chat, with no user message.
  3. Marks the run succeeded or failed and writes the next time to tasks.next_run_at.

Each task runs one pinned skill version, so its skill_tools list limits what the run may do. Only one run per task can be in progress.

A permission switch

Tools & Data screen → POST /permissions/{toolId}

  1. permissions.grant() or revoke() creates or updates the permissions row.
  2. A database trigger appends the change to permission_events.

Every switch starts off (granted = 0), so nothing is allowed until you turn it on.
